Coding guide

Code only what the article says. If it does not say it, choose Not stated. Do not guess, do not look the crash up, and do not use any AI tool.

Hard cases

SituationWhat to choose
“A man in his 40s”, “an elderly woman”Age: Not stated
A baby under one year oldAge: 0
Several pedestrians diedAge of the youngest; gender Mixed if they differ
“Police are searching for the vehicle”Driver left the scene: Yes
“No charges have been filed” or “charges are pending”Charges: None filed or pending
Charges never mentionedCharges: Not mentioned
“Just after 10 p.m.”, “on a poorly lit road”Light: Dark
“Tuesday morning” with no clock timeLight: Not stated
A cyclist was killedFirst question: No
Headline only, stub, or unrelated articleFirst question: No, and say so in the note
Several crashes in one articleCode the crash in the headline or first paragraph
Only a first name hints at genderGender: Not stated
Two ages given for the same personUse the one in the main text, and add a note
You genuinely cannot decideNot stated, with a short note

Some articles contain page code or repeated text from the website. Ignore it and read the story.
